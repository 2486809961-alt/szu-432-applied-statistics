# 规范：四级目录 / 命名 / 版式（全库唯一标准）

## 一、四级目录

```
C01 ... C18/                    L1 大类（18）
  第NN章 <名称>/                L2 章节（43）
    KNN <知识点名>/              L3 知识点与考点（73）
      KNN <知识点名>.md          课本内容 + 考法 + 题目清单
      YYYY-题型-NN <名>.md       L4 题目解析与复盘（152）
```

- L1：「C01 随机事件与概率」。
- L2：「第01章 事件与概率的基本概念」，章号 = 原板块序号。
- L3：「K01 样本空间、事件的关系与运算」，页与目录同名。
- L4：「YYYY-题型-NN 一句话考点.md」。

## 二、L3 页面结构（固定五段）

1. 一句话考点（callout abstract）
2. 一、课本内容 —— 1.1 教材原文定位表（条目 + 节号 + PDF 第 N 页（原书 p.M））｜1.2 推导与要点（纯文字，不嵌 PDF/图片）
3. 二、考法与真题分布 ｜ 三、易错点 / 我的笔记 ｜ 四、复盘三问
4. 五、题目清单（L4 全部真题链接）

## 三、教材与页码

- 教材：茆诗松《概率论与数理统计教程》第三版。
- 页码双标注：PDF ≤316 时 原书 = PDF − 17；PDF ≥321 时 原书 = PDF − 21；317–320 为误扫《贝叶斯统计》，禁引。
- 统计部分（C14–C18）茆诗松不覆盖：L3 页标「课本内容待补」，只留按考点归纳的要点，不编原文、不编页码。
- 本库不嵌 PDF 页图、不做荧光标注，课本内容一律文字承载。

## 四、硬规则

- 不编年份、不编教材原话；OCR 噪声注明「以原书为准」。
- 每题挂「考点码」，必须出现在对应 L3 页的题目清单里。
- 公式一律 LaTeX。
