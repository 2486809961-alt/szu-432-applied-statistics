# 规范：目录层级 / 命名 / 版式（全库唯一标准）

## 一、四层级目录（Obsidian 排序即按大写字母+数字前缀）

```
00 索引/
01 真题-原题试卷/        真题-YYYY-原题试卷.md
02 真题-解析试卷/        真题-YYYY-解析试卷.md
03 教材推导库/           推导-C01-K02 概率的加法公式.md
04 图谱/                （canvas）
C01 … C18/              ← 第一大类：18 章
   P01 …/               ← 第二大类：章下的大板块（节）
      K01 考点名.md      ← 第三大类：知识点与考点
      K01 考点名/        ← 第四大类（最小）：真题题目复盘
         2019-简答-01 xxx.md
99 模板与规范/
98 附件-原始试卷页/       YYYY_pN.png
```

- L1 = 18 大类（C01–C18），目录名必须是 `C01 随机事件与概率` 这种「代号 空格 名称」。
- L2 = 大板块（P01…），「P + 两位序号 空格 名称」。
- L3 = 考点页（K 前缀 .md），封面即考点本身；同名子目录放 L4。
- L4 = 单题复盘，文件名 `YYYY-题型-序号 一句话考点.md`，题型用 选择/填空/简答/计算/解答。

## 三、硬规则
- 页码双标注：`PDF 第 N 页（原书 p.M）`；原书页 = PDF 页 − offset，只算不写推导过程。
- 公式错位一律在题注写「**文本层公式错位，以页图为准**」，并嵌入 `![[98 附件-原始试卷页/2019_p2.png]]`。
- 不编年份、不编教材原话；OCR 噪声按上下文校正并注明「以原书为准」。
- 每道 L4 笔记必须含：原题、我的作答、标准答案/解析、考点关联、教材推导链接、复盘三问（错在哪/同类题/下次怎么做）。
- wikilink 用完整文件名（不带 .md）：`[[K60 概率抽样的组织形式与特点]]`。

## 五、教材页码换算（已核实，全库唯一口径）

- PDF 第 321 页起：**原书页 = PDF 页 − 21**（PDF 321 = 原书 p300）
节点：§5.4 三大抽样分布 PDF 266（p.249）｜§6.6 区间估计 PDF 321（p.300）｜第七章 PDF 335（p.314）｜第八章 PDF 394（p.373）。

## 六、题图命名与版式（v2）

- 原题裁切图：`98 附件-原始试卷页/题图/YYYY/YYYY-题型-NN.png`，续页 `-p2`、`-p3`。
- 解析裁切图：`98 附件-原始试卷页/题图解析/YYYY/YYYY-题型-NN-解析.png`。
- 试卷页 L4 一律「图先文后」：题图展开 → 折叠的「文本层原文（公式错位，仅作检索）」。
- 复盘页「一、原题」挂题图、「三、标准答案与解析」挂解析题图，文本层折叠。
- 严禁把文本层公式抄进正文；需要公式就用图。


## 七、复盘页 v2（六段式，全库强制）

每页结构固定：一、原题（题图，勿动）→ 二、考点定位 → 三、解题思路 → 四、完整解答 → 五、易错点 → 六、同类真题 → 七、我的复盘。

- 公式一律 LaTeX（$...$ / $$...$$），不准写 Unicode 上下标（σ²、χ² 这种）。
- 四段之后必须有「**答案**：」行，答案加粗或用 $ 包。
- 「六、同类真题」从该考点页的「同考点历年真题」表复制，链接必须可解析。
- 解析原件缺失（2026 计算 4–6、2024 部分）时，自行推导并在段首标「**本库自拟解答（原件无解析）**」。
- 禁止编年份、编页码；不确定的公式标「以题图为准」。
- 模板全文见 [[模板-单题复盘]]。
