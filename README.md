# 深圳大学 432 应用统计 · 历年真题 Obsidian 题库

把 2019–2026 共 8 年真题拆成 **152 道单题**，每题一篇笔记，配题图、考点链、教材推导依据与「张宇式」六段复盘。打开库就能知道：今天该刷哪一章、这题考什么、卡在哪一步、哪些年考过同样的考点。

> 纯 Obsidian 库，克隆后用 Obsidian 打开仓库根目录即可；不依赖任何插件也能读，装了 Dataview / Bases 更好用。

## 二、单题复盘长什么样（六段）

每篇统一结构，顺序固定，刷题时只填第七段：

1. **一、原题** — 原卷裁切图为主（公式以图为准），文本层折叠在下方仅供检索。
2. **二、考点定位** — 主考点双链、命题意图一句话、难度星级、教材推导依据（带双页码）。
3. **三、解题思路** — 「抓条件 → 选工具 → 落步骤」三步，写触发条件而不是复述题干。
4. **四、完整解答** — 分小问的块级 LaTeX，末尾一行 `**答案**：`。
5. **五、易错点** — 2–3 条具体错法（错在哪一步）+ 一句考场限时建议。
6. **六、同类真题** — 同考点跨年真题表（自动排除本题），带一句话差别。
7. **七、我的复盘** — 只留两个空位：错在哪 / 下次固定动作。

范例见 [2020-计算-03 回归方程的显著性检验与判定系数](<C12 回归分析/P02 回归方程的检验与预测/K53 回归方程的显著性检验与判定系数/2020-计算-03 回归方程的显著性检验与判定系数.md>)：散点判断 → 最小二乘 → F/t 检验，全程精算数字。

## 三、目录结构

```
00 索引/            首页 MOC、考点总索引、使用说明、真题总表
01 真题-原题试卷/    真题-YYYY-原题试卷.md（纯题面，按题号排列）

03 教材推导库/       推导-Cxx-Kyy 名称.md（教材原文推导 + 双页码）
04 图谱/            Canvas 全景图

99 模板与规范/       单题复盘模板、目录层级与命名规范、待核清单
C01 … C18/          大类 → P 板块 → K 考点 → 单题复盘
```

命名规范：`YYYY-题型-NN 考点名.md`，题型为 `选择 / 填空 / 简答 / 计算`。

## 四、怎么用

- **按章刷**：从 `00 索引/00 首页.md` 进大类，逐板块点下去。
- **按考点刷**：打开任意 `K` 页，底部表格就是该考点历年全部真题，点进去即复盘页。
- **按年份成套刷**：`01 真题-原题试卷/` 有整卷；做完对 `02 真题-解析试卷/`。
- **薄弱点定位**：在 `七、我的复盘` 里写字，然后用 Bases/Dataview 按「下次固定动作」聚合。
- **图谱**：`04 图谱/` 的 canvas 是 18 大类全景，可视化考点密度。

## 五、数据质量与已知限制（请先读）

真题原件是扫描件 + 图片批注式排版，本库做了以下处理，**残留问题都写在页内，不静默吞掉**：

- **2022 原题重度残缺**（单选只剩 1 题），能做的都做了，缺失的不补造。
- **2023 原题后 3 页含答案**：已把答案解析移入解析卷，原题卷只留题面；解析本只到选择第 6 题，故 2023 简答题的复盘标注「本库自拟解答（原件无解析）」。
- **2024 选择 12–20 / 填空 7–10** 未进入文本层，靠题图与 OCR 补齐，公式以图为准。
- **2026 为图片批注式**，解析本只到计算第 3 题；另有 5 处「题图与该题号文本层不一致」，集中登记在 [待核清单](<99 模板与规范/待核-2026图文与考点归属.md>)。
- **2019 解析卷编号与原题不对应**（解析的「简答 1–5」其实是原题简答 1 的五种抽样方法分条答案），简答题内容按关键词定位后落位。
- 全库共 **7 篇**标注「本库自拟解答（原件无解析）」，其余均按原件解析图写。
- 另有 2 题原件版式未切出裁图（2021-解答-03 / -04），页内用提示卡链到试卷，不伪造图。

教材页码口径：茆诗松《概率论与数理统计》第 3 版，`原书页 = PDF 页 − 17`；PDF 317–320 为误扫的《贝叶斯统计》第 7 章，不作引用。

## 六、贡献

- 发现某题解析与原件不符 → 提 issue，附年份 + 题号 + 原件截图。
- 想补某年缺失的题 → 请提供原卷 PDF，按 `99 模板与规范/规范-目录层级与命名.md` 加。
- 复盘写法统一走 [模板-单题复盘](<99 模板与规范/模板-单题复盘.md>)，提交前跑一遍结构自检（六段齐全 + `**答案**` 行 + 题图可解析 + 同考点表不含自身）。
