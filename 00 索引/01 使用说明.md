# 使用说明（四级结构）

## 目录怎么读

```
C01 随机事件与概率/              L1 大类：18
  第01章 事件与概率的基本概念/    L2 章节：43
    K01 样本空间.../             L3 知识点与考点：73（课本内容 + 考法 + 题目清单）
      2021-选择-01 ....md        L4 题目解析与复盘：152
```

## 三种用法

1. **背知识点**：L3 页「一、课本内容」= 教材原文定位表 + 推导要点，纯文字，页码直接对书。
2. **刷题**：L3 页「五、题目清单」是该考点全部真题；每题页含原题、解析、易错、复盘。
3. **总览**：02 大类总览 / 03 考点总索引 / 05 年份×考点矩阵。

## 关于课本内容

- 全部用文字承载：教材原文定位（条目 + §节号 + PDF 第 N 页（原书 p.M））+ 推导与要点，本库不再嵌 PDF 页图，也不做荧光标注。
- 统计部分（C14–C18）茆诗松不覆盖，L3 页标「课本内容待补」，只保留按考点归纳的要点。
