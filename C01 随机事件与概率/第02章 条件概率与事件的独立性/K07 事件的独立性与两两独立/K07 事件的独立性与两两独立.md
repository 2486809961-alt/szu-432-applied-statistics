# K07 事件的独立性与两两独立

> [!abstract] 一句话考点
> 独立 ⇔ P(AB)=P(A)P(B)；两两独立 ≠ 相互独立（还要全部子集成立）；独立时 P(A|B)=P(A)、P(AB̄)=P(A)P(B̄)。

### 1.2 推导与要点（文字）

### 2.1 从「无影响」到（1.5.1）

教材的出发点（原书 p.47）：独立性的意思是「一个事件的发生不影响另一个事件的发生」。掷两颗骰子，$A=$「第一颗为 1」，$B=$「第二颗为 4」，显然互不影响。

量化这条直觉：$P(Amid B)$ 与 $P(A)$ 的差别正是「$B$ 发生改变了 $A$ 发生的概率」。若无影响，则
$$P(Amid B)=P(A)quad	ext{且}quad P(Bmid A)=P(B),$$
两者都等价于
$$P(AB)=P(A)P(B). 	ag{1.5.1}$$

**关键一步**：教材指出「另外对 $P(B)=0$，或 $P(A)=0$，（1.5.1）式仍然成立」，而条件概率此时无定义——**所以必须用（1.5.1）而不是条件概率作定义**：

**定义 1.5.1**：如果（1.5.1）式成立，则称事件 $A$ 与 $B$ **相互独立**，简称 $A$ 与 $B$ 独立；否则称不独立或相依。

> 这是「为什么定义要用乘法而不用条件概率」的标准答案：**乘法公式在零概率场合依然有意义，条件概率没有。**

**判断独立的两条路**（教材明说）：多数实际问题按经验判断（相互有无影响）；有些问题用（1.5.1）式计算。例 1.5.1 给出的三个例子是后者的示范：

1. 52 张牌取 1 张，$A=$ 黑桃，$B=$ J。$P(A)=1/4, P(B)=4/52=1/13, P(AB)=1/52=P(A)P(B)$ ⟹ 独立。
2. 三个小孩的家庭（8 种等可能），$A=$「男女都有」$P=6/8$，$B=$「至多一个女孩」$P=4/8$，$AB=$「恰有一个女孩」$P=3/8=6/8	imes4/8$ ⟹ 独立。
3. **两个**小孩的家庭（4 种等可能），同样的 $A,B$：$P(A)=2/4, P(B)=3/4, P(AB)=2/4
e 3/8$ ⟹ **不独立**。

> 第 2、3 例是同一句话在样本量改变后独立性的翻转：**独立性是概率层面的性质，不是语义层面的性质**，必须验算。

### 2.2 性质 1.5.1：独立可以被「取对立」保持

**性质 1.5.1**：若 $A$ 与 $B$ 独立，则 $A$ 与 $ar B$、$ar A$ 与 $B$、$ar A$ 与 $ar B$ 都独立。

教材证明（原书 p.48）：
$$P(Aar B)=P(A)-P(AB)=P(A)-P(A)P(B)=P(A)ig[1-P(B)ig]=P(A)P(ar B),$$
故 $A$ 与 $ar B$ 独立；「类似可证 $ar A$ 与 $B$ 独立，$ar A$ 与 $ar B$ 独立」。

直观解释（教材原话）：$A$ 的发生不影响 $B$ 的发生，那么也不影响 $B$ 的不发生；$A$ 的不发生同理。

**推论（考场最常用的形态）**：若 $A_1,dots,A_n$ 相互独立，则
$$PBig(igcup_{i=1}^n A_iBig)=1-prod_{i=1}^{n}ig[1-P(A_i)ig].$$
因为 $overline{igcup A_i}=igcapar A_i$，再对 $ar A_i$ 用独立性。例 1.5.3（两射手，$0.9$ 与 $0.8$）：
$$P(Acup B)=1-(1-0.9)(1-0.8)=1-0.1	imes0.2=0.98,$$
与用加法公式 $0.9+0.8-0.9	imes0.8=0.98$ 一致。**「至少一个」一律走对立事件**，这是独立场合的标准动作。

### 2.3 三个事件：两两独立 $
e$ 相互独立

**定义 1.5.2**（原书 p.48）：设 $A,B,C$ 是三个事件，如果有
$$P(AB)=P(A)P(B),quad P(AC)=P(A)P(C),quad P(BC)=P(B)P(C), 	ag{1.5.2}$$
则称 $A,B,C$ **两两独立**。若还有
$$P(ABC)=P(A)P(B)P(C), 	ag{1.5.3}$$
则称 $A,B,C$ **相互独立**。

教材紧接着的一句是全章最重的警告：**「注意：有例子可以证明由（1.5.2）式推不出（1.5.3）式，同样有例子可以证明由（1.5.3）式推不出（1.5.2）式。」**

- **（1.5.2）⟹（1.5.3）不成立**的经典反例（教材未列出具体数值，此处按通行教材补，仅作理解用）：$Omega={1,2,3,4}$ 等可能，取
$$A={1,2},quad B={1,3},quad C={1,4}.$$
则 $P(AB)=P(AC)=P(BC)=dfrac14=dfrac12cdotdfrac12$（两两独立），但 $P(ABC)=P({1})=dfrac14
edfrac18$（不相互独立）。
- **（1.5.3）⟹（1.5.2）不成立**：$P(ABC)=P(A)P(B)P(C)$ 只约束三重交，完全可以与两两乘积不等同时成立。

**定义 1.5.3**（$n$ 个事件，原书 p.48–49）：对任意 $1le i<j<k<cdotsle n$，以下**所有**等式都成立
$$egin{aligned}
P(A_iA_j)&=P(A_i)P(A_j),\
P(A_iA_jA_k)&=P(A_i)P(A_j)P(A_k),\
& dots\
P(A_1A_2cdots A_n)&=P(A_1)P(A_2)cdots P(A_n),
end{aligned} 	ag{1.5.4}$$
则称 $A_1,dots,A_n$ **相互独立**。

**等式个数**：$n$ 个事件相互独立要求 $sum_{k=2}^{n}inom{n}{k}=2^n-n-1$ 个等式全部成立。$n=3$ 时是 $4$ 个（3 个两两 + 1 个三重），$n=4$ 时是 $11$ 个。**少验一个就不算相互独立**，这是选择题与判断题的固定陷阱。

教材同页的两条重要附注：
- 「$n$ 个相互独立的事件中的**任意一部分内仍是相互独立的**，而且任意一部分与另一部分也是独立的」；
- 「将相互独立事件中的任一部分换为对立事件，所得的诸事件仍为相互独立的」（性质 1.5.1 的多事件版本）。

### 2.4 例 1.5.2：独立性在集合运算下如何传递

**命题**：若 $A,B,C$ 相互独立，则 $Acup B$ 与 $C$ 独立。

证明（教材原文，原书 p.49）：
$$egin{aligned}
Pig((Acup B)Cig)&=P(ACcup BC)=P(AC)+P(BC)-P(ABC)\
&=P(A)P(C)+P(B)P(C)-P(A)P(B)P(C)\
&=ig[P(A)+P(B)-P(A)P(B)ig]P(C)=P(Acup B)P(C).
end{aligned}$$
中间那步用到 $A,B$ 独立（把 $P(A)+P(B)-P(A)P(B)$ 认成 $P(Acup B)$），最后一步也用 $A,B$ 独立。

**教材紧接着的警示**：仿此可推得 $AB$ 与 $C$ 独立、$A-B$ 与 $C$ 独立；**但「若 $A,B,C$ 间只有两两独立，则不能证明 $Acup B$ 与 $C$ 独立，也不能证明 $AB$ 与 $C$、$A-B$ 与 $C$ 独立」**——因为上面证明里用到了 $P(ABC)=P(A)P(B)P(C)$ 这一条，两两独立给不出它。

> 一句话记：**「相互独立」是一张通行证，可以做并、交、差、取对立；「两两独立」只保证两两乘积可拆。**

### 2.5 三个计算范例

**例 1.5.4（两道工艺，原书 p.49–50）**：第一种工艺三道工序不合格率 $0.3,0.2,0.1$，合格率
$$P(A_1)=0.7	imes0.8	imes0.9=0.504;$$
第二种工艺两道工序不合格率 $0.3,0.2$，合格率
$$P(A_2)=0.7	imes0.8=0.56 .$$
若第二种两道工序不合格率都改成 $0.3$，则 $P(A_2)=0.7	imes0.7=0.49<0.504$。**少一道工序相当于少乘一个小于 1 的因子**，这是工序设计的定量依据。

**例 1.5.5（轮流射击，原书 p.50）**：甲命中率 $alpha$，乙命中率 $eta$，甲先射。甲获胜
$$P=alpha+(1-alpha)(1-eta)alpha+ig[(1-alpha)(1-eta)ig]^2alpha+cdots=rac{alpha}{1-(1-alpha)(1-eta)}=rac{alpha}{alpha+eta-alphaeta}.$$
教材还给了**解法二（方程法，更快）**：
$$P(	ext{甲胜})=alpha+(1-alpha)(1-eta)P(	ext{甲胜}) Longrightarrow P(	ext{甲胜})=rac{alpha}{1-(1-alpha)(1-eta)} .$$
乙获胜 $=dfrac{eta(1-alpha)}{alpha+eta-alphaeta}$，两者相加为 1（可作验算）。教材还提醒等比级数求和需 $|(1-alpha)(1-eta)|<1$，由实际意义保证。

**例 1.5.6（系统可靠性，原书 p.50–52）**：每个元件正常概率 $p=0.9$。

- **串联**（全部正常才正常）：$P(S_1)=p^2=0.81$——可靠性**下降**。
- **并联**（至少一个正常）：$P(S_2)=1-(1-p)^2=0.99$——可靠性**上升**。
- **桥式**（5 元件）：以第 3 个元件为条件用全概率公式
$$P(S_3)=pig[1-(1-p)^2ig]^2+(1-p)ig[1-(1-p)^2ig]=0.9	imes0.9801+0.1	imes0.9639=0.9785 .$$
其中 $A_3$ 正常时系统化为「先并后串」，概率 $ig[1-(1-p)^2ig]^2=0.9801$；$A_3$ 不正常时化为「先串后并」，概率 $1-(1-p^2)^2=0.9639$。

### 2.6 试验的独立性与 $n$ 重伯努利试验

**定义 1.5.4**（原书 p.52）：若试验 $E_1$ 的任一结果与试验 $E_2$ 的任一结果都是相互独立的事件，则称两试验相互独立。$n$ 个试验的独立性类似；若这 $n$ 个独立试验还相同，称为 **$n$ 重独立重复试验**；若每次只有两个可能结果 $A$ 或 $ar A$，则称为 **$n$ 重伯努利试验**。

例 1.5.7（彩票，原书 p.52）：每周一张、坚持十年（520 次），每次中奖概率 $10^{-5}$，则从未中奖
$$P(A_1A_2cdots A_{520})=(1-10^{-5})^{520}=0.9948 .$$
改为万分之一时为 $0.9493$。**「独立重复」的算法就是连乘。**
