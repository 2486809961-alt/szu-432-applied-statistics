# K68 发展速度、增长速度与平均发展速度

> [!abstract] 一句话考点
> 发展速度=报告期/基期；增长速度=发展速度−1；平均发展速度=几何平均（n 个环比发展速度连乘开 n 次方）；平均增长速度=平均发展速度−1。

## 结论卡（贾俊平体系）

- 发展速度 = 报告期水平/基期水平；增长速度 = 发展速度 − 1
- 环比发展速度连乘 = 定基发展速度
- 平均发展速度 = ⁿ√(aₙ/a₀)（几何平均法，水平法）
- 平均增长速度 = 平均发展速度 − 1；几何平均法侧重期末水平，方程法（累计法）侧重累计总量
