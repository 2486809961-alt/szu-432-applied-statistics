# K34 相合性证明

> [!abstract] 一句话结论
> 相合性 = **估计量依概率收敛到真参数**。考试只需两条路：**(A) 大数定律 + 依概率收敛的四则运算/连续映射**（矩估计的通用兵器）；**(B) 定理 6.2.1：$E(\hat\theta_n)\to\theta$ 且 $\mathrm{Var}(\hat\theta_n)\to0$**（切比雪夫夹逼，适合 $x_{(n)}$ 这类非常规估计）。写证明时**三步走**：算期望 → 算方差 → 套定理。

## 二、推导过程

### 1. 定义 6.2.1：相合性到底在说什么

设 $\theta\in\Theta$ 为未知参数，$\hat\theta_n=\hat\theta_n(x_1,\dots,x_n)$ 是其估计。若对**任意** $\varepsilon>0$

$$\lim_{n\to\infty}P\big(|\hat\theta_n-\theta|\ge\varepsilon\big)=0, \tag{6.2.1}$$

则称 $\hat\theta_n$ 为 $\theta$ 的**相合估计**。

教材的两句评论值得原样记住（原书 p.274）：

> "相合性被认为是对估计的一个最基本要求……如果一个估计量，在样本量不断增大时，它都不能把被估参数估计到任意指定的精度，那么这个估计是很值得怀疑的。通常，不满足相合性要求的估计不予考虑。"

并且点明 (**6.2.1) 就是"$\hat\theta_n$ 依概率收敛于 $\theta$"**，所以一切依概率收敛的工具都能用：**切比雪夫不等式、大数定律、连续映射（定理 6.2.2）**。

### 2. 定理 6.2.1：期望到位 + 方差归零 ⇒ 相合

**条件**：$\lim_{n\to\infty}E(\hat\theta_n)=\theta$，$\lim_{n\to\infty}\mathrm{Var}(\hat\theta_n)=0$。
**结论**：$\hat\theta_n$ 是 $\theta$ 的相合估计。

**证明骨架（原书 p.274–275）**，共四步，考场上照抄这四步即可：

1. 切比雪夫不等式：对任意 $\varepsilon>0$，

$$P\big(|\hat\theta_n-E(\hat\theta_n)|\ge\varepsilon/2\big)\le\frac{\mathrm{Var}(\hat\theta_n)}{(\varepsilon/2)^2}=\frac{4\,\mathrm{Var}(\hat\theta_n)}{\varepsilon^2}.$$

2. 由 $E(\hat\theta_n)\to\theta$，当 $n$ 充分大时 $|E(\hat\theta_n)-\theta|<\varepsilon/2$；
3. 此时若 $|\hat\theta_n-E(\hat\theta_n)|<\varepsilon/2$，则三角不等式给出

$$|\hat\theta_n-\theta|\le|\hat\theta_n-E(\hat\theta_n)|+|E(\hat\theta_n)-\theta|<\varepsilon,$$

即事件包含关系 $\big\{|\hat\theta_n-E\hat\theta_n|<\varepsilon/2\big\}\subset\big\{|\hat\theta_n-\theta|<\varepsilon\big\}$，取对立事件得

$$\big\{|\hat\theta_n-\theta|\ge\varepsilon\big\}\subset\big\{|\hat\theta_n-E\hat\theta_n|\ge\varepsilon/2\big\};$$

4. 于是

$$P\big(|\hat\theta_n-\theta|\ge\varepsilon\big)\le P\big(|\hat\theta_n-E\hat\theta_n|\ge\varepsilon/2\big)\le\frac{4\,\mathrm{Var}(\hat\theta_n)}{\varepsilon^2}\to0 .\qquad\blacksquare$$

> **这个定理的实战价值**：它把"证明相合"降级成"算两个极限"。看到 $\hat\theta$ 结构怪异（最大值、最小值、比值）时，这是唯一可行的路。

### 3. 例 6.2.5：$x_{(n)}$ 为什么是 $\theta$ 的相合估计（$U(0,\theta)$）

这是定理 6.2.1 的标准示范，也是全章最经典的一道证明题。

**先要 $x_{(n)}$ 的分布**（教材引 §5.3.5 次序统计量结论）：$\theta=x_{(n)}$ 的密度

$$p(y)=\frac{ny^{\,n-1}}{\theta^n},\qquad 0<y<\theta .$$

**算期望**：

$$E(\hat\theta)=\int_0^\theta y\cdot\frac{ny^{n-1}}{\theta^n}\,\mathrm dy=\frac{n}{\theta^n}\cdot\frac{\theta^{n+1}}{n+1}=\frac{n}{n+1}\theta\ \longrightarrow\ \theta\quad(n\to\infty).$$

**算方差**（先算二阶矩）：

$$E(\hat\theta^2)=\int_0^\theta y^2\frac{ny^{n-1}}{\theta^n}\,\mathrm dy=\frac{n}{n+2}\theta^2,$$

$$\mathrm{Var}(\hat\theta)=\frac{n}{n+2}\theta^2-\Big(\frac{n}{n+1}\theta\Big)^2=\frac{n\,\theta^2}{(n+1)^2(n+2)}\ \longrightarrow\ 0 .$$

**套定理 6.2.1** ⇒ $x_{(n)}$ 是 $\theta$ 的相合估计。$\blacksquare$

> **顺手记一条**：$E(x_{(n)})=\frac{n}{n+1}\theta$ 说明 $x_{(n)}$ **有偏**（偏小），修正成 $\frac{n+1}{n}x_{(n)}$ 才无偏。这条在 [[推导-C08-K35 无偏估计与无偏性修正]] 里正是"无偏性修正"的招牌例子。

### 4. 定理 6.2.2：连续函数保持相合性

若 $\hat\theta_{n1},\dots,\hat\theta_{nk}$ 分别是 $\theta_1,\dots,\theta_k$ 的相合估计，$\eta=g(\theta_1,\dots,\theta_k)$ 是**连续函数**，则 $\hat\eta_n=g(\hat\theta_{n1},\dots,\hat\theta_{nk})$ 是 $\eta$ 的相合估计。

**证明思路（原书 p.275–276）**：对任意 $\varepsilon>0$，由 $g$ 连续存在 $\delta>0$ 使"各分量偏差 $<\delta$ ⇒ 函数值偏差 $<\varepsilon$"，即

$$\Big\{\bigcap_{j=1}^k\big\{|\hat\theta_{nj}-\theta_j|<\delta\big\}\Big\}\subset\big\{|\hat\eta_n-\eta|<\varepsilon\big\}.$$

取对立事件并用**次可加性（联合界）**：

$$P\big(|\hat\eta_n-\eta|\ge\varepsilon\big)\le\sum_{j=1}^k P\big(|\hat\theta_{nj}-\theta_j|\ge\delta\big)\le k\cdot\frac{\nu}{k}=\nu .$$

由 $\nu$ 任意 ⇒ 概率为 0。$\blacksquare$

> 这条定理是**"矩估计一般相合"的幕后推手**：矩估计就是把样本矩代入总体矩的表达式，而样本矩由大数定律相合、表达式是连续函数，两者一拼即得。

### 5. 教材给的三条"免费"相合结论（原书 p.276）

由大数定律 + 定理 6.2.2：

- $\bar X$ 是 $E(X)$ 的相合估计；
- $S$ 是 $\sigma$ 的相合估计；
- $S/\bar X$ 是总体变异系数的相合估计。

例 6.2.6 又给出三种频率替换估计 $\hat\theta_1=\sqrt{n_1/n}$、$\hat\theta_2=1-\sqrt{n_3/n}$、$\hat\theta_3=(n_1+n_2/2)/n$，因为 $n_i/n\xrightarrow{P}p_i$ 且开方/四则运算连续，三者都相合——**"相合估计不止一个"** 这句话的出处。

## 三、结论与适用条件

| 判据 | 适用场景 | 操作 |
|---|---|---|
| 定义 (6.2.1) 直接验证 | 分布完全已知、能算出 $P(|\hat\theta-\theta|\ge\varepsilon)$ | 少用 |
| 大数定律 + 依概率收敛性质 | 矩估计、样本矩的函数 | 最常用（快） |
| **定理 6.2.1**（期望→$\theta$、方差→0） | $x_{(n)}$、$x_{(1)}$、比值型估计 | 上述两条都不好走时用 |
| **定理 6.2.2**（连续映射） | 已知若干分量相合，求复合参数 | 与上面配合 |

**必须分清的三组概念**

| 概念 | 含义 | 关系 |
|---|---|---|
| 无偏性 | $E(\hat\theta)=\theta$（对每个 $n$） | 小样本性质 |
| 相合性 | $\hat\theta_n\xrightarrow{P}\theta$ | 大样本性质 |
| 渐近无偏 | $E(\hat\theta_n)\to\theta$ | 介于两者之间 |

- **无偏 ⇒ 相合？** 不一定。$\hat\theta=X_1$（只取第一个观测）无偏但**不相合**（方差恒为 $\sigma^2$ 不趋于 0）。
- **相合 ⇒ 无偏？** 不一定。$x_{(n)}$ 相合但有偏（$\frac{n}{n+1}\theta$）。
- 由定理 6.2.1 可见：**渐近无偏 + 方差趋于 0 = 相合**。所以"无偏 + 方差→0"是相合的充分条件。

## 四、考场用法

**题型 1｜"证明 $\hat\theta$ 是 $\theta$ 的相合估计"**
固定四行答案：
1. 写出 $\hat\theta_n$ 的分布或密度（次序统计量、$\chi^2$、伽马等）；
2. 算 $E(\hat\theta_n)$，指出 $\to\theta$；
3. 算 $\mathrm{Var}(\hat\theta_n)$，指出 $\to0$（常需先算 $E(\hat\theta^2)$）；
4. "由定理 6.2.1 知 $\hat\theta_n$ 是 $\theta$ 的相合估计。"

**题型 2｜"判断下列估计是否相合"**
- 形如 $\bar X$、$S^2$、$\frac1n\sum X_i^k$ 的 → 大数定律，**直接判相合**；
- 形如 $a\bar X+b$ 但 $a\ne1$ → 看是否 $a\to1$；
- 只依赖有限个观测（如 $X_1$、$X_1+X_2$）→ **不相合**，一句话点破"方差或随机性不随 $n$ 消失"。

**题型 3｜"相合性为什么是对估计的最基本要求"**（简答）
答三个层次：① 它保证"数据足够多时能估到任意精度"；② 它不依赖具体分布形式，只需大数定律条件；③ 不具备相合性的估计**不予考虑**（教材原话），而其他标准（无偏、有效）都是在此基础上锦上添花。

**易错点**
- 忘写"对任意 $\varepsilon>0$"，只对某个 $\varepsilon$ 验证，逻辑不成立；
- 定理 6.2.1 里把"$\mathrm{Var}\to0$"漏掉，只写"$E\to\theta$"就下结论（反例：$\hat\theta=X_1$）；
- 用定理 6.2.2 时不验证**连续性**。
